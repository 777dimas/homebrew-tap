# 777dimas/tap

Homebrew formulae for [gridhour](https://github.com/777dimas/gridhour), when UK electricity is green and cheap, in your terminal.

```sh
brew install 777dimas/tap/gridhour
gridhour SW1A
```

Works on macOS and on Linux with Homebrew. The formula builds gridhour from its PyPI release. Problems with the formula go here; problems with gridhour itself go to [its issues](https://github.com/777dimas/gridhour/issues).
